# EE1010-Project-Submissions-2026

## Submission Procedure

Note: Only ONE person from each team should submit.

1. Fork this repo to your own account (you need a GitHub account)
2. Clone it onto your device. Ensure that you are cloning your OWN repo, not this repo (URL will be of the form `https://github.com/<YOUR-USERNAME>/EE1010-Project-Submissions-2026`).
3. Add your files in the structure specified below (note: not following the file structure specified below may result in issues with evaluating your submission, so please ensure everything is fine before commiting.
4. Add, commit and push the files as we demoed in class (if you were unable to follow along, you can rely on your friends or online resources for the same. If still having issues, contact a TA well before submission deadline).
5. After pushing the files, navigate to your repo on GitHub, and go to your project folder.
6. On the top right, you will find an option to copy permalink to that commit version of your project.
7. Open the shared Google Form, fill in your team details, and the permalink to your committed files (note that only permalinks will be considered for evaluation. Submitting normal links will result in non-evaluation of your project).

## Submission file structure

* In the repo, create a folder whose name contains both teammates' roll numbers, separated by underscores. Eg: If EE26BTECH11201 and EE26BTECH11202 are teamed up, the folder will be named `ee26btech11201_ee26btech11202`.
* Inside this folder, create a folder for the project you want to submit. Eg: If you want to submit the digital clock project, make the subfolder named `digital_clock`.
* Inside this project folder, upload all relevant files. Note that any files not uploaded and submitted in time will not be considered for evaluation later. Also, all files uploaded here will be used for the viva, so do not upload content you are not confident in.

Example overall structure:
```
.
├── README.md
└── ee26btech11201_ee26btech11202/
    └── digital_clock/
        ├── source_code.cpp
        ├── progress_log.pdf
        ├── progress_log.tex
        └── README.md
```
